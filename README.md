# FakeBTC

Simulador de trading de Bitcoin. Gráfico de velas en vivo y paper trading apalancado a 100x, con 1.000 USD ficticios.

- Velas BTC/USDT de Binance, de 1 minuto a 1 día
- Indicadores: SMA 21, cruce de medias y MACD
- Comprar y vender, equity y PnL en tiempo real
- PWA instalable

## Desarrollo

```bash
npm install
npm run dev
```

La app queda en `http://localhost:8080`.
